# 📊 Global Sales Dashboard - Tableau

## Overview
This project presents an interactive Sales Dashboard developed in Tableau to analyze and visualize sales performance across different countries, product lines, deal sizes, and customers.

## Dashboard Features
- Sales Trend Analysis
- Country-wise Sales Performance
- Product Line Sales Analysis
- Deal Size Analysis
- Top Customers Analysis

## Tools Used
- Tableau
- Excel Dataset

## Key Insights
- USA generated the highest sales.
- Classic Cars emerged as the top-selling product line.
- Medium deal size contributed the highest revenue.
- Euro Shopping Channel was the top customer.
